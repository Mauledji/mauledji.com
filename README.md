# mauledji.com — Personal Portfolio

Fullstack Software Engineer.
Built with Astro, React y Tailwind CSS. Deployed in Cloudflare Pages.

## Stack

- **Framework** — Astro
- **UI interactivo** — React
- **Estilos** — Tailwind CSS v4 + CSS
- **Animaciones** — GSAP + Canvas API
- **Formulario de contacto** — Resend
- **i18n** — Bilingüe EN / ES
- **Deploy** — Cloudflare Pages
